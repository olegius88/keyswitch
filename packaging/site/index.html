Набирайте, не глядя на раскладку

KeySwitch исправляет слова, набранные в неверной раскладке: ghbdtn становится «привет», руддщ — «hello». Работает в Windows, Ubuntu и macOS; распознавание идёт на вашем компьютере.

Что умеет

Решение «оставить, исправить или подождать следующее слово» принимают небольшие обученные модели, которые учитывают соседние слова. Программа не дообучается на вашем наборе и не отправляет его в сеть.

После пробела, знака или паузы

Слово исправляется, как только оно закончено: пробелом, знаком препинания или паузой в наборе (0,7 с, настраивается).

Ранняя смена раскладки

Если начало слова уже ясно, раскладка меняется до его конца: ghbd → «прив», дальше вы печатаете по-русски.

Учитывает контекст

Короткие и неоднозначные слова решаются по соседям; при сомнении программа ждёт следующее слово.

Клавиша Pause

Преобразует последнее слово вручную, а повторное нажатие возвращает его обратно. Клавишу можно назначить другую.

Отмена и пауза

Ctrl+Alt+Z отменяет последнее исправление в течение 10 секунд, Ctrl+Alt+P приостанавливает работу.

Исключения и правила

Программы и слова, которые не трогать; правила для отдельных слов — по двойному нажатию Pause.

Регистр и знаки

Ghbdtn → «Привет»; запятые, точки и кавычки в словах другой раскладки исправляются вместе со словом.

Индикатор EN/RU

Буквы или флаги в области уведомлений, меню по щелчку, светлая и тёмная тема, уведомления и звук.

Обновления

В Windows новая версия ставится сама после проверки SHA-256, в Ubuntu приходит через APT. Всё отключается в настройках.

Скриншоты

Окно настроек в Windows 11. В macOS окно то же, в Ubuntu — нативное окно GTK.

Установка

Версия @VERSION@. Все файлы и их контрольные суммы (SHA256SUMS) — на странице выпуска.

Windows

Установка для текущего пользователя, без прав администратора.

  • Установщик x64 — Windows 10/11
  • Установщик ARM64 — Windows 11 на ARM
  • Установщик x86 — 32-битная Windows 10

Без установки: архивы x64, ARM64, x86 — распакуйте и запустите KeySwitch.exe. Файлы пока не подписаны, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

macOS 13 и новее

Подписано Developer ID и нотаризовано Apple.

  • Apple Silicon (M1 и новее)
  • Intel

Перенесите KeySwitch.app в «Программы». При первом запуске программа попросит разрешение «Универсальный доступ» — без него она не видит клавиатуру. Новые версии скачиваются отсюда же.

Ubuntu

X11 и Wayland (GNOME, KDE Plasma 6, sway), amd64.

  • Пакет .deb: sudo apt install ./keyswitch_@VERSION@_amd64.deb

Пакет сам подключает этот подписанный репозиторий APT, и новые версии приходят вместе с обновлениями системы. В сеансе Wayland доступ к клавиатурам включается один раз командой sudo keyswitch --enable-wayland-input.

Репозиторий APT

Здесь лежат подписанные пакеты KeySwitch для Ubuntu: @SUITE@ @COMPONENT@, архитектура @ARCHITECTURE@. Команды ниже ставят KeySwitch сразу из репозитория, без ручной загрузки .deb:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URI@@KEYRING_FILE@ | sudo tee @KEYRING_PATH@ >/dev/null
sudo tee /etc/apt/sources.list.d/keyswitch.sources <<'EOF'
Types: deb
URIs: @URI@
Suites: @SUITE@
Components: @COMPONENT@
Architectures: @ARCHITECTURE@
Signed-By: @KEYRING_PATH@
EOF
sudo apt update && sudo apt install keyswitch

Чтобы перестать получать обновления отсюда, добавьте Enabled: no в /etc/apt/sources.list.d/keyswitch.sources или удалите этот файл.

Конфиденциальность

Нажатия клавиш, слова и решения моделей обрабатываются на том компьютере, где запущен KeySwitch. Набранный текст, правила, история и журнал никуда не отправляются. В памяти находятся текущее слово и до 512 символов недавнего текста поля; в историю попадают только пары вида ghbdtn → привет.

Единственные сетевые запросы — проверка новых версий на GitHub (её можно выключить) и, в Ubuntu, обращения APT к этому репозиторию.

Свободная программа

KeySwitch распространяется на условиях GNU GPL 3.0 или более поздней версии. Исходный код, модели, правила их обучения и проверки открыты.

English

KeySwitch fixes words typed in the wrong keyboard layout between English and Russian (ghbdtn → «привет», руддщ → “hello”) and switches the system layout with them, on Windows, Ubuntu (X11 and Wayland) and macOS. Small trained models decide every word on your computer; nothing you type leaves it. Free software under GPL-3.0-or-later.

Download version @VERSION@ above or from the release page. This address is also the signed APT repository for Ubuntu (suite @SUITE@, component @COMPONENT@, architecture @ARCHITECTURE@): an installed package registers it itself, and the commands in the APT section install straight from here. To stop taking updates from it, add Enabled: no to /etc/apt/sources.list.d/keyswitch.sources or delete the file.
