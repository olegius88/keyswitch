KeySwitch APT repository

Здесь лежат подписанные пакеты KeySwitch для Ubuntu: @SUITE@ @COMPONENT@, архитектура @ARCHITECTURE@. Установленный пакет добавляет этот репозиторий сам, поэтому новые версии приходят вместе с остальными обновлениями системы. Команды ниже нужны только для установки сразу отсюда, без ручной загрузки .deb.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URI@@KEYRING_FILE@ | sudo tee @KEYRING_PATH@ >/dev/null
sudo tee /etc/apt/sources.list.d/keyswitch.sources <<'EOF'
Types: deb
URIs: @URI@
Suites: @SUITE@
Components: @COMPONENT@
Architectures: @ARCHITECTURE@
Signed-By: @KEYRING_PATH@
EOF
sudo apt update && sudo apt install keyswitch

English

This is the signed APT repository for KeySwitch on Ubuntu: suite @SUITE@, component @COMPONENT@, architecture @ARCHITECTURE@. An installed package registers the repository itself, so later versions arrive with the rest of the system updates; the commands above install straight from here instead.

To stop taking updates from this repository, add Enabled: no to /etc/apt/sources.list.d/keyswitch.sources or delete the file.
