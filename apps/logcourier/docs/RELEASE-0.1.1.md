# LogCourier 0.1.1

Отдельное приложение для сбора логов; версия KeySwitch не меняется.

- Windows: один установщик `LogCourier-Setup-0.1.1-x64.exe`, установка для текущего
  пользователя, ярлыки, обновление и удаление с сохранением настроек, токена и очереди.
- Оконный `LogCourier.exe` без пустой консоли; для диагностики — `LogCourier-cli.exe`.
- Закрытие окна скрывает приложение в доступный трей. Полный выход — через меню трея.
- Автозапуск при входе в Windows включается отдельно во вкладке «Отправка».
- Мелкие фрагменты логов объединяются в пакеты до 19 МБ. Документы и закрепления
  ограничены по частоте; серверная пауза Telegram сохраняется после перезапуска.
  Нулевая вероятность HTTP 429 не гарантируется: бот может использоваться другими клиентами.
- Проверка настоящего упакованного GUI и цикл установки/обновления/удаления добавлены
  в Windows CI. Тесты Telegram используют имитацию API, без отправки пользовательских логов.

Перед обновлением выберите «Выход» в трее старого сборщика. Если ранее использовали
переносимую версию с автозапуском, выключите и снова включите автозапуск в установленной
копии — это обновит путь. Две копии с одним профилем одновременно не запускайте.

Токен и личные логи в дистрибутив не входят. Установщик не включает отправку и автозапуск.
Контрольные суммы поставляются рядом с файлами. Linux-архив собран на Ubuntu 26.04;
совместимость с более старыми дистрибутивами не проверена.
