# LogCourier 0.1.3

Отдельный выпуск сборщика логов для Windows и Linux. Версия KeySwitch не меняется.

## Изменения

- Закреплённый каталог опознаётся по SHA-256 из подписи сообщения. Telegram со
  временем выдаёт тому же документу новый `file_id`, и сравнение по нему после
  долгого перерыва навсегда останавливало отправку сообщением «Закрепление
  каталога потеряно или изменено», хотя закрепление оставалось на месте.
- По этой же сумме сверяются каталог до и после загрузки архивов и незавершённая
  запись каталога: прерванная отправка восстанавливается и через сутки, а не
  только в ближайшие минуты.
- Сборщик, остановленный прежней ошибкой, после обновления продолжает прежнюю
  цепочку каталогов и отправляет накопленную очередь. Восстанавливать что-либо
  вручную не нужно.
- Если в группе не закреплено ничего, отказ остаётся прежним: новая цепочка
  каталогов не начинается молча, и последний каталог по-прежнему следует вернуть
  в закрепление. Подмена каталога другим процессом также останавливает отправку.
- Незавершённая запись каталога прежнего формата пересобирается из очереди;
  уже загруженные архивы повторно не отправляются.
- Идентификаторы `file_id`, записанные в прежних каталогах, остаются пригодными
  для скачивания: `list` и `fetch` читают историю как раньше.

## Обновление

Windows: скачайте `LogCourier-Setup-0.1.3-x64.exe`. Перед установкой выберите
«Выход» в трее старого сборщика. Настройки, очередь и системное хранилище токена
сохраняются. Не запускайте одновременно две копии с одним профилем.
Для переносимой копии с автозапуском после установки выключите и снова включите
автозапуск в установленной версии, чтобы обновить путь.

Установщик не включает отправку и автозапуск без вашего выбора. Личные логи,
токены и приватные инструкции в дистрибутив не входят. Linux ZIP собирается
на Ubuntu 26.04; более старые дистрибутивы не проверены.

## Проверки и ограничения

Перед публикацией требуются успешные нативные сборки Windows и Linux,
проверка упакованного GUI, а на Windows — установка, обновление и удаление.
Контрольные суммы SHA-256 поставляются рядом с файлами.

Имитация Telegram в тестах теперь, как и сервис, выдаёт для одного документа
новый `file_id` на каждый запрос; на прежнем коде такой набор тестов не проходит.
Поведение сверено и с ответами живого Bot API на уже закреплённый каталог —
только чтением, без отправки логов.

Живая отправка архивов и реальный вход в Windows-сессию в рамках этого выпуска
не проверяются. Полное исключение HTTP 429 не гарантируется, особенно при
использовании бота другими клиентами.
