# LogCourier 0.1.2

Отдельный выпуск сборщика логов для Windows и Linux. Версия KeySwitch не меняется.

## Изменения

- При первом определении и смене версии KeySwitch в группу отправляется документ
  «МАРКЕР ВЕРСИИ». Обновление и откат определяются по заголовкам самого лога,
  а не по версии установленного исполняемого файла.
- Фрагменты разделяются на границах версий; ZIP-пакеты не смешивают разные
  версии и источники KeySwitch. Сохраняются исходные байты и многострочные записи.
- Актуальная версия проверяется по активному файлу до разбора старой очереди.
  Маркеры используют общий ограничитель частоты отправки Telegram.
- Команды `list` и `fetch` по умолчанию выбирают текущую подтверждённую версию
  каждого источника. Для другой версии есть `--keyswitch-version X.Y.Z`,
  для всей истории — `--all-versions`.
- Старые архивы без метаданных не считаются актуальными автоматически и не
  удаляются. При неизвестной версии требуется явный выбор истории.
- Подборка для анализа сохраняется отдельно, с `selection.json` и SHA-256;
  состояние интерфейса показывает версии настроенных источников.

## Обновление

Windows: скачайте `LogCourier-Setup-0.1.2-x64.exe`. Перед установкой выберите
«Выход» в трее старого сборщика. Настройки, очередь и системное хранилище токена
сохраняются. Не запускайте одновременно две копии с одним профилем.
Для переносимой копии с автозапуском после установки выключите и снова включите
автозапуск в установленной версии, чтобы обновить путь.

Установщик не включает отправку и автозапуск без вашего выбора. Личные логи,
токены и приватные инструкции в дистрибутив не входят. Linux ZIP собирается
на Ubuntu 26.04; более старые дистрибутивы не проверены.

## Проверки и ограничения

Перед публикацией требуются успешные нативные сборки Windows и Linux,
проверка упакованного GUI, а на Windows — установка, обновление и удаление.
Контрольные суммы SHA-256 поставляются рядом с файлами.

Версионные сценарии Telegram проверяются на имитации API, без отправки личных
логов. Живая отправка новых маркеров и реальный вход в Windows-сессию в рамках
этого выпуска не проверяются. Полное исключение HTTP 429 не гарантируется,
особенно при использовании бота другими клиентами.
