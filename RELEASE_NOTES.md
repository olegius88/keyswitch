# KeySwitch 0.2.1

Этот выпуск добавляет ожидаемое поведение после самостоятельной смены
раскладки пользователем.

## Изменения

- KeySwitch отличает ручную смену XKB-группы от собственного автоматического
  переключения.
- Первое завершённое слово после ручного выбора языка остаётся без
  автокоррекции; затем обычное распознавание автоматически возобновляется.
- Смена обнаруживается как по следующему событию клавиатуры, так и фоновым
  опросом, поэтому поддерживаются горячая клавиша и системный индикатор.
- В разделе «Автокоррекция» добавлен включённый по умолчанию переключатель
  «Доверять ручной смене раскладки».
- Unit/GTK-набор расширен до 125 тестов при 100% покрытии строк и ветвей.
- Исходный и пакетный X11 E2E проверяют ручную смену, одноразовую защиту слова
  и последующее возобновление автоматического исправления.

## Установка

Для 64-битной Ubuntu на x86 скачайте `keyswitch_0.2.1_amd64.deb` и установите
его командой:

```bash
sudo apt install ./keyswitch_0.2.1_amd64.deb
```

Затем запустите `KeySwitch` из меню приложений или командой `keyswitch`.

Текущий backend предназначен для X11. Нативная Wayland-сессия пока не
поддерживается.
