# KeySwitch 0.2.0

Вторая версия KeySwitch делает автоматическое распознавание раскладки заметно
более точным и добавляет системную интеграцию уровня зрелого переключателя.

## Возможности

- ансамблевое распознавание EN/RU: частоты Onboard, Hunspell, символьные
  n-граммы и краткий контекст;
- защита кода, URL, сокращений, неоднозначных и технических слов;
- явное локальное самообучение по ручному преобразованию и Undo;
- переключение системной XKB-группы вместе с исправлением текста;
- поддержка русских букв на пунктуационных физических клавишах;
- ручное преобразование последнего слова, отмена и глобальная пауза;
- исключения приложений через выбор окна, каталог или ручной WM_CLASS;
- локальная история исправлений;
- полноценное окно настроек GTK 4 / Libadwaita;
- автозапуск после входа в ОС и индикатор EN/RU либо флагами;
- всплывающее меню индикатора по левому клику с быстрыми настройками, историей,
  исключениями, сведениями о программе и выходом;
- встроенная диагностика X11 RECORD, XTEST и XKB.
- регрессионный барьер на 40 000 слов, unit- и реальный X11 E2E-тест.
- нативный архитектурный ELF-пакет, собранный Nuitka без исходных `.py` и
  байткода `.pyc`, с отдельным E2E-тестом уже запакованного бинарника.

## Установка

Для 64-битной Ubuntu на x86 скачайте `keyswitch_0.2.0_amd64.deb` и установите
его командой:

```bash
sudo apt install ./keyswitch_0.2.0_amd64.deb
```

Затем запустите `KeySwitch` из меню приложений или командой `keyswitch`.

Текущий backend предназначен для X11. Нативная Wayland-сессия пока не
поддерживается.
