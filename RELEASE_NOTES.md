# KeySwitch 0.1.0

Первый публичный выпуск KeySwitch — автоматического корректора раскладки для
Ubuntu с X11.

## Возможности

- автоматическое исправление слов в раскладках EN/RU;
- переключение системной XKB-группы вместе с исправлением текста;
- ручное преобразование последнего слова, отмена и глобальная пауза;
- исключения приложений и слов;
- локальная история исправлений;
- полноценное окно настроек GTK 4 / Libadwaita;
- автозапуск и индикатор в системной панели;
- встроенная диагностика X11 RECORD, XTEST и XKB.

## Установка

Скачайте `keyswitch_0.1.0_all.deb` и установите его командой:

```bash
sudo apt install ./keyswitch_0.1.0_all.deb
```

Затем запустите `KeySwitch` из меню приложений или командой `keyswitch`.

Текущий backend предназначен для X11. Нативная Wayland-сессия пока не
поддерживается.
